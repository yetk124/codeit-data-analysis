# 데이터 설명

원본 CSV는 저장소에 포함하지 않았습니다. 모두 공개 데이터이므로 아래 출처에서 내려받을 수 있습니다.
노트북 실행 시 Google Drive `MyDrive/초급 프로젝트/` 경로에 파일을 두면 됩니다.

| 파일 | 출처 | 주요 컬럼 |
|---|---|---|
| 서울시 지하철 호선별 역별 유_무임 승하차 인원 정보 (202505-202604) | [서울 열린데이터광장](https://data.seoul.go.kr) | 사용월, 호선명, 지하철역, 유임승차인원, 무임승차인원, 유임하차인원, 무임하차인원 |
| 시군구별 고령인구 비율 | [KOSIS 국가통계포털](https://kosis.kr) | 시도, 자치구, 65세 이상 인구, 고령인구비율 |
| 서울시 경로당 정보 | [서울 열린데이터광장](https://data.seoul.go.kr) | 시설명, 주소 (→ 지오코딩으로 위도·경도 변환) |
| 서울교통공사 역별 일별 시간대별 노인 승하차인원 (2025) | [공공데이터포털](https://www.data.go.kr) | 수송일자, 역번호, 역명, 승하차구분, 06시 이전 ~ 24시 이후 (20개 시간대) |

서울 자치구 경계 GeoJSON은 [southkorea/seoul-maps](https://github.com/southkorea/seoul-maps)를 노트북에서 직접 불러옵니다.
